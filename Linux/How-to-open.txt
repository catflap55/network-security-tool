This folder is for Linux only.

PERSONAL USE ONLY. Home network that you own only.

1. Install packages (see README.md, Linux section)
2. Right-click Start.sh → Run as a program / Run in Terminal

If nothing happens, in Terminal:
  cd into this Linux folder, then:
  bash Start.sh

Leave that window open while you use the app.
In the browser try http://localhost:5173 and http://127.0.0.1:5173
(they are the same app). If one fails, use the other.
More detail: ../README.md  (Linux section)
